# 2026-09-20 독서 프로필 모달 — 모바일에서 탭 줄이 잘리던 문제

랭킹 페이지에서 사람을 누르면 뜨는 독서 프로필 모달. 모바일 폭에서 "완독한 책 11 / 남긴 리뷰 21"
탭 줄이 위아래로 잘려 보이고, 목록이 더 길면 아예 안 보이기도 했다.

## 원인

`.sheet`는 `max-height`(모바일 88vh)가 걸린 flex 컬럼이고, 그 안에 머리(`.who`)·탭(`.tabs`)·
목록(`.list`)이 세로로 쌓인다. 그런데 셋 다 `flex-shrink` 기본값이 1이었다.

내용이 `max-height`를 넘으면 브라우저는 **모든 flex 항목을 기본 크기에 비례해 같이 줄인다.**
목록이 대부분을 흡수하지만 탭 줄(약 41px)도 제 몫만큼 눌려, 글자가 잘리거나 사라졌다.
`.list`에 `overflow-y: auto`만 있고 `flex: 1; min-height: 0`이 없어서 "목록만 줄어든다"는
보장이 없었던 것.

## 한 일

- `.who`, `.tabs` → `flex: none` (줄어들지 않음)
- `.list` → `flex: 1; min-height: 0` (남는 높이를 받아 그 안에서만 스크롤)
- `tests/readerProfileModal.test.ts` 2건 추가 — 스코프드 CSS에서 위 선언을 확인한다.
  수정을 되돌리면 실제로 실패하는 것까지 확인했다(전체 259건 통과).

## 검증

헤드리스 Chrome(390×844)으로 같은 구조를 렌더해 수정 전후를 비교했다.
수정 전에는 탭 글자가 위아래로 잘렸고, 수정 후에는 탭 줄이 온전히 보이고 목록만 스크롤된다.

같은 패턴(`flex-direction: column` + 내부 `overflow-y: auto`)을 쓰는 다른 화면
(ChatWidget, PostComposer, places)은 이미 `flex: 1; min-height: 0`을 갖고 있어 문제가 없었다.
