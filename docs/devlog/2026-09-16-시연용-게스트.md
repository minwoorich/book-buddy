- **게스트 선점 화면**: 결정은 [[decisions/2026-09-16-시연용-게스트-선점]].
  - DB: `users.is_guest`, `guest_claims(user_id PK, token, claimed_at)` — migrate.ts에 ALTER/CREATE 가드.
  - 서버: `guestRepo`(list/claim/release/releaseAll/resolveUser), `optionalUser`가 게스트면 `x-guest-token` 검증.
    라우트 `GET /api/guests`, `POST /api/guests/:id/claim`(409), `DELETE /api/guests/claim`, `GET /api/guests/me`,
    `POST /api/admin/guests/release-all`.
  - 클라이언트: `useCurrentUser`가 게스트 토큰도 보관(localStorage `bb:guest-token`), `useApi`가 헤더로 실음,
    401 문구를 게스트용으로 분기. `/login` 상단 게스트 카드(3초 폴링, 사용 중 비활성). 헤더 로그아웃이 선점 해제.
    `guest-heartbeat.client.ts`가 게스트만 10초마다 세션 확인. 관리자 회원 페이지에 "게스트 전체 해제" 버튼 + 게스트 뱃지.
  - `scripts/guest-seed.ts`: 게스트 1~N 멱등 생성, `--remove`로 활동 기록까지 삭제.

## 시연 운영 메모

- 켜기: `railway ssh ... -- npx tsx scripts/guest-seed.ts` (게스트 5명). 끄기: 같은 명령에 `--remove`.
- 심사 사이 리셋: 관리자(도서관리자) → 회원 → "게스트 전체 해제". 접속 중인 게스트는 10초 안에 로그아웃된다.
- 게스트가 5명을 넘으면 카드가 전부 "사용 중" — 그때는 기존 로그인 폼(발표자 계정) 또는 회원가입.
