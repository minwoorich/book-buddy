# 2026-09-16 피드 글쓰기 개편 + 해시태그

결정 문서: [[../decisions/2026-09-16-피드-글쓰기-인스타식-개편]]

## 한 일

**서버 / DB**

- `post_tags(post_id, tag, sort_order)` + `idx_post_tags_tag (tag COLLATE NOCASE)` — migrate.ts에 `CREATE TABLE IF NOT EXISTS`로 추가(기존 DB 그대로 부팅된다).
- `shared/utils/hashtags.ts` — 정규화 규칙을 클라이언트·서버가 공유한다. `normalizeTag`(앞의 `#`·기호 제거, 20자), `normalizeTags`(중복·대소문자 무시, 10개), `extractHashtags`(캡션에서 `#태그` 추출), `mergeTags`, `parseTagsField`(JSON 배열 또는 쉼표 구분).
- `postTagRepo` — `replace`(트랜잭션으로 통째 교체), `listByPost`, `listByPosts`(피드 N+1 방지), `popular`.
- `postRepo.listAll`에 `tag` 옵션(EXISTS 서브쿼리, NOCASE) 추가 + 모든 게시물에 `tags` 동봉. `remove`가 `post_tags`까지 지운다.
- `POST /api/posts`가 `tags` 폼 필드를 받고 캡션의 `#태그`와 합쳐 저장. `PATCH /api/posts/:id`는 `tags`를 보내면 교체, 안 보내면 기존 칩 유지(어느 쪽이든 캡션 태그는 다시 합친다). `GET /api/posts?tag=` 필터, `GET /api/posts/tags` 인기 태그.

**프런트**

- `FeedPostComposer` 전면 재작성 — `Teleport`로 모달, 드롭존(끌어다 놓기 포함) → 사진 스테이지 + 썸네일 스트립(대표 지정 ★, 제거 ×, 추가 +) / 문구 · 해시태그 · 책 태그. 배경 스크롤 잠금, Esc 닫기, 작성 중 닫으면 확인.
- `FeedTagInput` 신규 — 칩 입력. Enter·쉼표·스페이스로 확정, 빈 칸 Backspace로 마지막 칩 삭제, 인기 태그 제안 칩. **`e.isComposing` 가드**로 한글 조합 중 Enter에 글자가 잘리지 않게 했다.
- `FeedPostCard` — 캡션 안 `#태그`를 눌러지는 조각으로 쪼개 렌더(`captionParts`), 칩으로만 단 태그는 아래 한 줄(`extraTags`, 캡션에 이미 있으면 중복 제거). 수정 모드에서 태그도 편집.
- `feed.vue` — 컴포저 바("무슨 책 읽고 계세요?"), 인기 태그 바, 태그 클릭 필터, 모바일 FAB. 제목·글쓰기 버튼을 본문 컬럼(540px) 폭에 맞춰 가운데 정렬.

## 막힌 것 / 푼 것

- **전역 `.me`와 충돌**: 모달 작성자 줄에 `class="me"`를 썼더니 main.css의 `.me { margin-left: auto }`(헤더 사용자 영역용)가 먹어 모바일에서 이름이 오른쪽으로 밀렸다. 스코프 스타일은 전역 규칙을 막지 못한다 → `.author`로 개명.
- **`##` 이중 표시**: 칩 앞에 `::before { content: '#' }`를 두고 입력 필드 앞에도 안내용 `#`를 둬서 `# #자동화테스트`로 보였다 → 칩이 하나라도 있으면 안내용 `#`를 숨긴다.
- **헤드리스 검증이 멈춤**: 모달 닫기의 `confirm()`이 네이티브 다이얼로그를 띄우면 CDP `Runtime.evaluate`가 영원히 안 돌아온다 → `Page.javascriptDialogOpening`을 받아 자동 수락하게 했다.
- **`npm run seed:demo` 재실행 실패(기존 버그)**: 삭제 목록에 `notices`·`place_reviews`·`guest_claims`가 빠져 있어 `DELETE FROM users`가 FK로 막혔다. 이번에 목록을 채웠다.
- **빌드 EPERM**: `node .output/server/index.mjs`가 떠 있으면 `better-sqlite3` prebuild 파일을 못 지운다 → 빌드 전에 서버를 내린다.
