# 2026-09-16 랭킹에서 사람을 눌러 그 사람의 완독 책·리뷰 보기

랭킹은 "누가 몇 권 읽었다"까지만 보여줬다. 1위가 12권이라는 건 알지만 **무슨 책을** 읽었는지,
읽고 뭐라고 했는지는 볼 방법이 없었다. 순위표가 숫자 경쟁으로만 끝나고 책 추천으로 이어지지 않았다.

민우의 요청: 랭킹 화면에서 사람을 클릭하면 그 사람이 읽은 책 정보와, 리뷰를 남겼다면 리뷰도 볼 수 있게.

## 고른 형태

세 가지를 놓고 물었다 — **모달(팝업)** / 전용 프로필 페이지(`/users/[id]`) / 행 아래 펼쳐지는 아코디언.
민우가 모달을 골랐다. 순위표를 벗어나지 않고 보다가 닫으면 원래 순위 그대로 남는 게 이 화면의 용도에
맞고, `books/[id].vue`에 이미 있는 `modal-back`/`modal` 패턴을 그대로 쓸 수 있다.

버린 것 — 프로필 페이지는 URL 공유·북마크가 되고 나중에 피드나 리뷰 작성자 이름에서도 같은 곳으로
보낼 수 있어 확장성이 좋지만, 페이지 신설 + "랭킹으로 돌아가기" 동선이 붙는다. 지금 필요한 건
"순위표를 보다가 궁금한 사람을 열어보는" 동작이라 모달이 더 짧다. 아코디언은 책·리뷰가 많으면
목록이 길어져 순위표가 흐트러진다.

## 개인 탭에서만 열린다

`RankRow.userId`는 개인 랭킹일 때만 채워진다. 팀·부서·계열사 줄은 집계라 열 사람이 없다.
그래서 `canPick(row)`는 `row.userId !== undefined` 하나로 판정하고, 이 값이 클릭 가능 여부·커서·
`role="button"`·`tabindex`를 모두 결정한다. 탭 이름(`by`)을 따로 보지 않는다 — 데이터에 사람이
있으면 열리고 없으면 안 열린다.
