# 2026-09-15 반응형 UI (모바일 대응)

민우 요청으로 전 페이지 반응형 적용. 결정 배경은 [[decisions/2026-09-15-반응형-모바일-대응]].

## 한 일

- `main.css`에 공통 반응형 규칙: 네비(모바일 2줄 + 메뉴 가로 스크롤), `.wrap` 여백, 패널/탭/표, FAB 위치, `.table.stack-sm`·`.table-scroll` 유틸리티.
- `useShelfColumns` 컴포저블 + `chunk()` 유틸(테스트 3건) — `BookShelfRow`(6→4→3칸), `ShelfSection`(8→5→3칸, 줄 단위 선반 렌더로 재구성).
- 페이지별 `@media`: 홈, 검색 결과, 책 상세(표지 중앙 + 세로 배치), 내 서재(2단→1단, 읽는 중 행 줄바꿈, 책쌓기 위젯), 달력(달력+사이드 1단, 셀 축소), 랭킹(포디움 축소, 행 줄바꿈), 리뷰, 피드, 장소(지도+목록 1단, 검색바 줄바꿈), 로그인/회원가입, 관리자 4페이지(타일 2열/1열, 2단→1단, 표 스택/스크롤).
- 컴포넌트: 헤더(모바일에서 이름·부제 숨김), 챗봇 전체화면, QA 패널, AI 검색 패널, 검색바, 카테고리 칩 가로 스크롤, 책쌓기, 포디움, 달력 셀, 리뷰 폼, 차트 2종, 지도 높이, 책 등록 행, 피드 카드.
- 검증: 빌드 통과, vitest 46건 통과, CDP 스크린샷 390/768px 전 페이지 가로 넘침 0건. 스크린샷 검토로 잡은 것 2건 — 내 서재 "읽고 있는 책" 행이 좁게 눌리던 것(반납일을 둘째 줄로), QA 패널 보내기 버튼이 챗봇 FAB에 가려지던 것(z-index).

## 2차 점검 — "깨진 것들" 찾기

민우 요청("깨진 것, 엉클어지는 것 확인")으로 360/520/700/1000px과 열린 상태(글쓰기 폼, 신고 모달, 희망도서 폼, 통계 표, 랭킹 탭)를 추가 캡처(112장). 가로 넘침은 0건, 눈으로 잡은 것:

- **내 서재 프로필(640~900px)**: 프로필 텍스트와 책쌓기 위젯이 한 줄에 눌려 "많이 읽은 분
야", "올해 3권 완
독"처럼 낱말이 세로로 쪼개짐 → 위젯을 900px부터 아래 줄로, 뱃지·숫자는 nowrap.
- **내 서재 "내가 남긴 리뷰"(360px)**: "책 보기" 버튼 옆에서 본문이 4~5줄로 접힘 → 본문 기준 폭을 줘 버튼을 아래 줄로. 처음 `> div` 셀렉터로 잡았다가 표지 컴포넌트 루트(div.cv)까지 걸려 표지가 풀폭으로 커지는 회귀 발생 → 클래스(rv-body)로 한정. 인라인 `style="flex:1"`이 클래스 규칙을 이기던 것도 원인.
- **통계 표 머리글(360px)**: "완독/대출/인원/인당"이 글자 단위로 세로 분리 → 모바일에서 th nowrap.
- **통계 가로막대 라벨(모든 폭)**: 90px 고정 열에서 "바텍 · 개발본
부"처럼 낱말 중간 줄바꿈 → 열을 minmax(90px,170px)로, word-break keep-all.
- **피드 글쓰기**: 브라우저 기본 파일 입력("파일 선택 | 선택된 파일 없음")이 모바일에서 어수선 → "사진 추가" 버튼(label)로 감싸고 선택 장수를 옆에 표시.
- **통계에 "����" 그룹**: 반응형 문제가 아니라 데이터. users id 84가 이름·회사·부서·팀·직급 전부 깨진 문자(테스트 가입 시 한글이 잘못된 인코딩으로 들어간 것으로 보임) → 삭제 여부 민우 결정 대기.

## 3차 점검 — 모델 바꿔서 재검증 (Fable)

민우 요청("아까 소넷으로 했는데 Fable로 다시 확인")으로 코드 리뷰 + 헤드리스 캡처를 처음부터 다시 돌렸다(390/768px 전 페이지 16장×2 + 챗봇/QA 패널 열린 상태).

- **코드 리뷰**: `useShelfColumns`가 setup에서 바로 `matchMedia`를 읽는 건 `ssr: false`라 하이드레이션 불일치 없음. `chunk`·행 단위 선반 렌더·`stack-sm` 표 유틸 모두 문제 없음.
- **users id 84 삭제** — 민우 승인 후 로컬 DB에서 삭제(연결 데이터 0건 확인). 나머지 유저에 깨진 문자 없음 전수 스캔. 통계의 `����` 그룹은 이 계정 하나가 원인이었으므로 같이 해결. 로컬 curl 가입 테스트 때 cp949 인코딩으로 들어간 것으로 보이며, 운영 DB에는 없을 가능성이 높음(운영은 브라우저 가입만).
- **통계 가로막대(390px)**: 2차에서 라벨 열을 64px로 줄이고 말줄임을 걸었더니 "바텍 · 개…", "레이언스 …"로 전부 똑같이 잘려 어느 부서인지 구분 불가 → 모바일에서는 라벨을 막대 위 한 줄(`grid-column: 1 / -1`)로 올림. 재캡처로 확인.
- 자동 넘침 검사에서 걸린 2건은 의도된 것: `/admin/ai` 호출 기록 표(`.table-scroll` 가로 스크롤), `/places` 768px의 카카오 지도 타일(컨테이너 안 overflow hidden).
- 캡처 스크립트는 `/books/1`을 찍고 있었는데 로컬엔 그 id가 없어 "책을 찾을 수 없어요"만 찍혔음 → 실제 id로 바꿔 책 상세도 확인 완료.
- vitest 46/46, 빌드 통과.
