# 2026-09-16 페이지 이동 로더

## 배경

페이지 이동마다 1~2초 무반응 — SPA(`ssr: false`)라 이동 = 페이지 청크 다운로드 + setup의 `await useAsyncData`(API 응답) 대기. Railway 서버가 느리면 그 공백이 그대로 보인다. 결정은 [[decisions/2026-09-16-페이지-이동-로더]].
