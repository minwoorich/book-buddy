# 2026-09-15 관리자 회원 페이지 — 사람별 대출·반납 이력

민우 요청: "관리자 페이지에서 사람별로 대출, 반납 이력 같은 것도 다 확인할 수 있게. 사람들도 보고"

## 구현

- **`/admin/members` 회원 목록**: 전원(139명)을 이름·소속·대출중·연체·완독·리뷰·마지막 활동 순으로. 이름/회사/부서/팀 검색, 전체·대출중·연체·활동 없음 필터, 연체자 행은 배경 강조. 마지막 활동 최신순 정렬(활동 없는 사람은 뒤).
- **`/admin/members/:id` 회원 상세**: 프로필(소속·첫 대출일) + 집계 타일(대출중·연체·완독·늦은 반납·리뷰) + 대출·반납 이력 표(책·대출일·반납 예정·반납일·상태) + 남긴 리뷰. 상태는 `대출중 (D-n)` / `연체 n일` / `반납` / `반납 (n일 늦게)`로 구분. 전체/대출중/반납 필터.
- **서버**: `memberRepo.summaries()`(사람별 집계 SQL 한 번), `loansOf`, `reviewsOf`. `GET /api/admin/members`, `GET /api/admin/members/:id` — 관리자 전용(requireAdmin). 연체 판정은 SQL에서 `due_at`(ISO)을 `datetime('now')` 형식으로 맞춰 비교.
- 관리자 헤더에 "회원" 메뉴(대시보드 다음).

## 검증

- vitest 97/97(신규 memberRepo 3건: 집계 수치·정렬·이력/리뷰 조회), 프로덕션 빌드 통과.
- 빌드 서버 스모크: 일반 회원의 목록 요청 403, 관리자 목록 200(72명), 상세 200(대출 6건·리뷰 15건), 없는 id 404.
