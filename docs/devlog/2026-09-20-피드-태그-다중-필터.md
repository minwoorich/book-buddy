# 2026-09-20 피드 — 태그를 여러 개 걸 수 있게

피드 태그 바에서 `#옥상`을 고른 뒤 `#완독`을 누르면 **앞 태그가 갈아치워졌다.**
필터처럼 생겼는데 한 번에 하나만 걸린다.

## 원인

화면의 `activeTag`가 문자열 하나였고(`app/pages/feed.vue`), 서버도 `?tag=` 한 개만 받아
`post_tags.tag = ?` 로 비교했다. 애초에 다중 선택이 들어갈 자리가 없었다.

## 정한 것 — AND가 아니라 OR

두 태그를 고르면 **하나라도 달린 글**을 보여준다.
AND(둘 다 달린 글)가 '필터'라는 말에는 가깝지만, 지금처럼 게시물이 적을 때는
두 번째 태그를 누르는 순간 거의 0건이 된다. 관심 태그 모아보기 쪽이 쓸모 있다.

## 한 일

- `shared/utils/hashtags.ts`
  - `parseTagQuery(raw)` — `?tag=옥상`, `?tag=옥상&tag=완독`, `?tag=옥상,완독`을 모두 받는다.
    기존 `normalizeTags`를 그대로 태워서 `#` 제거·대소문자 무시 중복 제거·최대 10개가 공짜로 따라온다.
  - `toggleTag(selected, raw)` — 칩 토글(대소문자 무시). 화면 로직을 순수 함수로 빼서 테스트했다.
- `server/repositories/postRepo.ts` — `listAll` 옵션이 `tag?: string` → `tags?: string[]`.
  `EXISTS(... AND pt.tag COLLATE NOCASE IN (?,?,...))` — EXISTS라 태그가 겹쳐도 같은 글이 두 번 안 나온다.
- `server/api/posts/index.get.ts` — `parseTagQuery`로 쿼리를 받는다. `?tag=옥상` 단일 링크는 그대로 동작.
- `app/pages/feed.vue` — `activeTags: string[]`. 고른 칩이 앞에 `×`와 함께 줄지어 서고,
  2개 이상이면 맨 앞에 `모두 해제` 칩(점선 테두리)이 붙는다. 빈 상태 문구도 `#옥상, #완독 …`로.
- 테스트 4건 추가 (전체 321건 통과)

확인: 로컬 dev 서버에 `?tag=옥상` 1건, `?tag=옥상&tag=완독` 2건 — OR로 넓어진다.
