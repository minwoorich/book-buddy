## 리스크 메모

- 기능 누적으로 **1일 분량을 명확히 초과** → 막히면 우선순위(위에서부터 사수):
  1. 대출/반납 + 챗봇 도구 실행
  2. AI 검색 영역
  3. 마이페이지 책장 / 도서 달력
  4. 랭킹
  5. 구매신청 / 예약 / 리뷰 추천
  6. 관리자 대시보드 (책 등록·신청 처리까지, 통계는 그다음)
  7. 커뮤니티 피드 / 장소 추천 / 통계 차트 (시간 남으면)
- 준비물 추가: `NAVER_MAP_CLIENT_ID`(NCP), `NAVER_SEARCH_CLIENT_ID/SECRET`(개발자센터) — 발급처가 다름
- 알라딘 API 응답 형식은 시드 작성 시 실제 호출로 확인 필요 ([[../references/외부-API|외부 API 정리]])
