# 팀 QA 체크리스트

- 대상: https://book-buddy-production-27b4.up.railway.app (설치 불필요, 폰·PC 모두)
- 방법: 아래 시나리오를 따라 해보고, **이상하면 화면 왼쪽 아래 [QA] 버튼**으로 한 줄 신고 (페이지·화면크기 자동 첨부)
- 테스터는 로그인 화면에서 서로 다른 직원을 골라주세요 (겹치면 데이터가 섞여 보여요)
- 민우는 관리자 화면 `/admin/qa`에서 접수분을 보고 수정 → push → 자동 재배포

## 시나리오

**A. 검색·AI (메인)**
1. 로그인 → 메인 진입, 카테고리 칩 전환 시 서가가 바뀌는가
2. 키워드 검색("팀장") → 결과 리스트·상태 뱃지 정상인가
3. 자연어 검색("팀장이 처음인데 리더십 책 추천해줘") → AI 영역에 답변+책 카드가 뜨는가
4. AI 답변의 액션 버튼 클릭 → 올바른 페이지로 이동하는가
5. 모바일(폰)에서 메인이 깨지지 않는가

**B. 대출·책 상세**
6. 대출가능 책 → [대출하기] → 뱃지가 "대출중"으로 바뀌는가
7. 남이 대출 중인 책 → [예약하기] 동작, 내 서재 예약 목록에 뜨는가
8. 리뷰 작성(별점+한줄) → 목록에 반영, 👍 추천 토글·중복 방지 되는가
9. 찜 토글 → 찜 수 변화, 내 서재 찜 선반에 반영되는가
10. 분실·파손 신고 → 접수 알림이 뜨는가

**C. 내 서재·달력·랭킹**
11. 내 서재: 대출 중 책의 D-day가 맞는가, [반납] 후 읽은 책 선반·책쌓기에 반영되는가
12. 책쌓기 권수(올해/이달)가 실제 완독 수와 일치하는가
13. 달력: 반납한 날짜에 표지가 뜨는가, 월 이동이 되는가
14. 랭킹: 개인/팀/부서/계열사 탭 전환, 내 순위 하이라이트가 맞는가
15. 새로고침(F5) 후에도 각 페이지가 정상 표시되는가

**D. 피드·장소·챗봇**
16. 피드: 사진 업로드+책 태그 게시 → 목록 반영, 좋아요·댓글 동작하는가
17. 장소: 목록·(예시)지도 표시, [AI 추천받기] 클릭 시 동작 또는 안내가 뜨는가
18. 챗봇: "리더십 책 추천해줘" → 책 카드·버튼이 뜨는가
19. 챗봇: "그 책 대출해줘" → 실제 대출되고 내 서재에 반영되는가
20. 챗봇이 제안한 [리뷰 쓰러가기] 버튼 → 리뷰 폼으로 이동하는가

**E. 관리자 (도서관리자 계정)**
21. 대시보드 수치(대출 중/연체/신청/신고)가 실제와 맞는가
22. 희망도서 승인/거절, 신고 처리 동작하는가
23. 통계: 그룹 전환 시 차트가 갱신되는가
24. `/admin/qa`: 테스터 신고가 쌓이고 [해결] 처리되는가
