# 2026-09-13 독서활동 기능 4종 추가

민우 지시: "위 기능들도 있으면 좋겠어"

## 추가된 기능

1. **도서 달력** — 대출 후 반납이 완료되면 달력의 그 날짜에 책 표지가 등록됨
2. **독서 진행률** — 얼마나 읽었는지 기록. 북적북적 앱의 "책쌓기" 기능처럼 누적 시각화
3. **마이페이지 책장** — 읽은 책 / 읽고 있는 책 / 찜한 책을 실제 책장에 꽂힌 느낌으로
4. **사내 독서 랭킹 보드** — 개인별 / 계열사별 / 부서별 / 팀별 등

## 설계 반영 (Claude 해석 포함)

- 새 테이블: `wishlists`(찜), `reading_progress`(진행률). `users`에 계열사/부서/팀 필드, `books`에 page_count 추가
- 판정 규칙: **반납 = 완독**으로 간주 (느슨). 읽고 있는 책 = 대출 중, 달력 = 반납일 기준
- 랭킹 기준: 기간 내 완독 권수 1순위, 페이지 수 2순위. 탭으로 개인/팀/부서/계열사 전환
- 새 화면: `/calendar`, `/rankings`, `/my`는 책장 메타포로 개편
- 챗봇 도구 추가: `add_wishlist`, `record_progress`, `get_my_reading_stats`, `get_rankings`
- 시드: 랭킹·달력이 그럴듯하도록 직원 12명(계열사×부서×팀 구성), 반납 완료 대출을 날짜 분산해 다수 생성
