# 2026-09-13 페이지 진행률 제거 · 랭킹 기준 확정

## 결정 (민우)

1. **"읽고 있는 책"에서 페이지 표시 제거** — 책 구독 서비스가 아니라서 사용자가 몇 페이지를 읽고 있는지 시스템이 알 수 없음
2. **랭킹 보드에서 페이지 기록 제거**
3. **랭킹은 무조건 대출-반납 기록 기준으로 카운팅**

## 반영

- `reading_progress` 테이블, 진행률 API(`PUT /api/books/:id/progress` 등), 챗봇 `record_progress` 도구 **설계에서 삭제**
- 랭킹·책쌓기·통계 모두 **기간 내 반납 완료 권수**로만 집계. 동률은 공동 순위. 페이지 수 집계·표시 없음
- 마이페이지: 읽고 있는 책에는 대출일·반납 기한(D-day)만 표시, 진행률 바/페이지 기록 버튼 삭제
- 목업 반영: [my.html](../../design/mockups/v1a/my.html), [rankings.html](../../design/mockups/v1a/rankings.html), [calendar.html](../../design/mockups/v1a/calendar.html)에서 쪽수·진행률 요소 제거
- `books.page_count`는 책 자체 정보(상세 페이지 "344쪽" 표기)로만 유지
