# 2026-09-16 피드 글쓰기 — 인스타식 모달 + 해시태그

## 결정

민우 지적: "피드 페이지 글쓰기 쪽 ui/ux 가 너무 ai 틱하고 그냥 너무 형편없어. 좀 개선해봐. **인스타 스럽게. 그리고 태그도 달 수 있게해**"

기존 컴포저는 피드 위에 그냥 펼쳐지는 패널이었다. "사진 추가" 버튼 + 빈 회색 textarea + 책 검색창이 세로로 나열돼 있어, 빈 상태에서 화면 대부분이 아무것도 없는 큰 사각형이었다(민우가 캡처한 화면).

- **모달로 분리(A안).** 인스타 "새 게시물 만들기"와 같은 2단계 흐름 — ① 사진 드롭존 → ② 왼쪽 사진 미리보기·썸네일 스트립 / 오른쪽 문구·해시태그·책 태그. 헤더는 `× / 새 게시물 만들기 / 공유하기`. `Teleport to="body"` + 배경 스크롤 잠금 + Esc 닫기.
- **피드 맨 위 컴포저 바.** "무슨 책 읽고 계세요, OOO님?" 한 줄을 누르면 모달이 열린다. 빈 입력창을 항상 펼쳐 두지 않고도 글쓰기 진입점이 눈에 남는다.
- **해시태그는 칩 입력 + 캡션 내 `#태그` 둘 다.** 칩으로 고르는 쪽이 오타·띄어쓰기 문제가 없고, 인스타 사용자는 문구에 바로 `#`를 쓴다. 서버가 둘을 합쳐 저장하므로 어느 쪽으로 써도 같은 태그가 된다. 최대 10개, 태그당 20자.
- **태그 저장은 `post_tags` 한 곳.** `posts.tags` 같은 JSON 컬럼을 두지 않는다 — 태그로 거르는 조회(`EXISTS`)와 인기 태그 집계(`GROUP BY`)가 둘 다 필요하기 때문.
- **태그 비교는 대소문자 무시.** `Book`과 `book`은 같은 태그. 표기는 먼저 쓰인 쪽을 남긴다.
- **피드에 태그 바 + 태그 클릭 필터.** 게시물의 태그나 상단 인기 태그를 누르면 그 태그 글만 본다. 같은 칩을 다시 누르면 해제.
- **모바일은 전체화면 모달 + FAB.** 헤더의 "글쓰기" 버튼은 스크롤하면 사라지므로 ≤600px에서는 숨기고 우하단 FAB으로 대체(챗봇 FAB 위 88px).

## 버린 대안

- **기존 패널을 그대로 두고 태그 줄만 추가**: 원인(빈 화면이 휑하고 위계가 없다)을 안 건드린다.
- **태그를 고정 목록에서만 고르기**(장소 후기 칩처럼): 장소 후기는 "조용해요/콘센트" 같은 닫힌 축이라 고정이 맞지만, 독서 게시물의 태그는 열린 축이다.
- **`posts.tags` JSON 컬럼**: 태그 필터·집계 쿼리가 문자열 LIKE로 새어 나간다.
- **태그 자동완성 드롭다운**: 인기 태그 칩 제안으로 충분. 과하다(YAGNI).
