# 2026-09-13 커뮤니티 피드 · 장소 추천 기능 추가

민우 지시로 기능 2종 추가.

## 추가된 기능

1. **커뮤니티 피드** (`/feed`) — 인스타그램처럼 간단한 사진 업로드 + 좋아요 + 댓글
   - 테이블: `posts`(책 태그 선택 가능), `post_likes`, `post_comments`
   - 사진은 로컬 디스크(`.data/uploads/`) 저장, 외부 스토리지 없음 (데모)
2. **책 읽기 좋은 장소** (`/places`) — 네이버 지도 연동 + AI 추천
   - 네이버 지역검색 API로 주변 카페·도서관·공원 검색 → Claude가 "책 읽기 좋은 순" 큐레이션(추천 이유 한줄)
   - 지도는 네이버 지도 JS SDK 마커 표시. 키 없으면 리스트만 표시로 폴백

## 필요한 키 (민우가 준비)

- `NAVER_MAP_CLIENT_ID` — 네이버클라우드플랫폼(NCP) Maps
- `NAVER_SEARCH_CLIENT_ID` / `NAVER_SEARCH_CLIENT_SECRET` — 네이버 개발자센터 지역검색
- 주의: 두 키는 **발급처가 다른 별개 시스템**

## 범위 주의 (Claude 기록)

- 기능 누적: 검색/AI + 대출반납 + 예약 + 구매신청 + 리뷰(+추천) + 달력 + 진행률/책쌓기 + 책장 + 랭킹 + 피드 + 장소. **1일 분량을 명확히 초과**
- 우선순위상 피드와 장소는 **가장 마지막**(시간 남으면)으로 배치 — [[../plans/로드맵|로드맵]]
