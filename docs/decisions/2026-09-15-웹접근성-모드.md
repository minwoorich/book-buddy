# 2026-09-15 웹 접근성 모드 (큰 글씨·단순 화면 / 색약 모드 / 다크모드)

## 결정

민우 요청: "노인 혹은 시각장애분들을 위해 ① UI 글자 키우기 및 단순 버전 ② 색맹·색약 모드 ③ 다크모드 구현하자". 방식은 "권장되는 방법으로" Claude에 위임. 설계서는 [[../superpowers/specs/2026-09-15-web-accessibility-modes-design|접근성 모드 설계]].

- **설정 4종을 헤더 "접근성" 버튼 하나에 모은다**: 글자 크기(보통/크게/아주 크게), 단순 화면, 색약 모드, 화면 테마(시스템/라이트/다크). 관리자 헤더·로그인·회원가입에도 같은 버튼.
- **기기 단위 저장(localStorage `bb:a11y`)**: 계정이 아니라 기기에 묶이는 성질이고, 게스트도 써야 한다. 앱 시작 시 플러그인이 복원(로그인 사용자 복원과 같은 패턴).
- **CSS는 `<html>`의 `data-*` 속성만 본다**: 기본 화면 규칙은 손대지 않고 모드는 덮어쓰기 계층으로만. ver1a 디자인은 기본 모드에서 그대로.
- **글자 크기는 `zoom`(130%/160%)**: px가 303곳이라 rem 변환은 비용 대비 이득이 없고, 브라우저 확대처럼 레이아웃·아이콘이 비례 확대돼 고정폭이 넘치지 않는다.
- **색약 모드에서 바텍 레드는 유지**: 적록 색약의 문제는 "빨강 vs 초록"이라 초록(대출가능)을 파랑(#0072B2, 오카베-이토)으로, 경고를 주황으로 바꾸면 해소된다. 색 외 단서로 "✓ 대출가능 / ✕ 대출중", 뱃지 앞 기호(✓ ! –), 차트 막대 파랑.
- **다크모드는 토큰만 덮어쓴다**: 컴포넌트에 흩어져 있던 하드코딩 색 약 60곳을 새 토큰 20개(`--text-2`, `--hover`, `--cover-bg`, `--star`, `--overlay`, `--shadow` 등)로 먼저 모은 뒤 `[data-theme=dark]`에서 교체. 레드는 어두운 배경에서 #FF4438로 보정(디자인 규칙).
- **단순 화면**: 서가 질감·표지 그림자·호버 애니메이션·영문 eyebrow 제거, 링크 밑줄, 버튼·입력 최소 높이 44px, 테두리 2px, 포커스 링 3px. 키보드 포커스 링(`:focus-visible`)은 모든 모드에 전역 추가.

## 버린 대안

- **px→rem 전면 변환**: 303곳 수정, 결과는 zoom과 같음.
- **서버 계정 저장**: 게스트 미지원, 기기별 시력 환경 반영 불가.
- **`prefers-color-scheme`만 따르는 자동 다크**: 발표 시연에서 즉시 전환이 안 됨 → 수동 3단 + 시스템 옵션.
- **색약 모드에서 레드까지 교체**: 브랜드 정체성 훼손.
