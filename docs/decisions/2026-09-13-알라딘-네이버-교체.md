# 2026-09-13 도서 데이터 API: 알라딘 → 네이버 책 검색 교체

## 결정 (민우)

- "알라딘 API가 이제 종료된대. 다른 API 쓰자" → 알라딘 의존 전면 제거

## 대체 선택 (Claude 제안, 민우 위임)

**네이버 책 검색 API** (`openapi.naver.com/v1/search/book.json`)

- 이유: 장소 추천(지역검색)과 **같은 네이버 개발자센터 키** 사용 → 발급처 3곳 → 2곳으로 축소. 표지·소개·ISBN·출판사 제공
- 대안이던 카카오 책 검색은 키가 별도라 제외

## 영향과 처리

| 항목 | 변경 |
|---|---|
| `aladinService` | `naverBookService.search(clientId, clientSecret, query)`로 교체 |
| 시드 전략 | 베스트셀러 목록 API가 없음 → **카테고리별 키워드 검색**(예: IT → "클린코드", "프로그래밍")으로 수집, ISBN 중복 제거 |
| `page_count` | 네이버 미제공 → null 허용, 화면에서 null이면 쪽수 표기 생략 |
| `GET /api/aladin/search` | `GET /api/book-search`로 교체 (희망도서·관리자 책 등록용) |
| AI 도구 `search_aladin` | `search_external_books`로 교체 |
| 환경변수 | `NUXT_ALADIN_TTB_KEY` 제거. `NUXT_NAVER_SEARCH_CLIENT_ID/SECRET` 재사용 |
| 표지 화질 | 네이버 image URL의 `?type=` 쿼리 제거 시 원본 해상도 — 시드에서 적용 |

기존 구현(Task 4·7·9·10)에 리팩터 태스크(4R)로 소급 적용.
