2. 배포 전략 질문 → Claude 제안으로 확정:
   - 데모 당일은 **로컬 실행** (dev 또는 build + node)
   - 원하면 **Docker 단일 컨테이너** (SQLite + 업로드 폴더 볼륨)
   - **서버리스 배포 제외** — SQLite 파일 DB·로컬 업로드와 안 맞음

   - 프론트: components를 도메인별 폴더(book/ai/review/reading/feed/admin/common)로, composables 분리
   - `shared/types/`로 서버·프론트 도메인 타입 공유. 전부 TypeScript
