# 2026-09-16 페이지 이동 로더 — 책등 3권 스피너

## 결정

민우 요청: "페이지 이동할 때마다 반응이 느려 … 어디든 페이지 이동할 때마다 스피너 넣는 게 좋겠어. 바텍 도서관에 걸맞는 스피너 한 개 미니멀한 느낌으로."

- **트리거는 Nuxt 내장 `useLoadingIndicator`.** `page:loading:start`→`page:loading:end`(NuxtPage Suspense pending→resolve)에 이미 묶여 있어 청크 다운로드와 setup의 `await useAsyncData` 대기를 한 번에 덮는다. 라우터 훅을 직접 붙이면 데이터 대기를 놓친다.
- **150ms 스로틀.** 그보다 빠른 이동은 아예 뜨지 않아 깜빡임이 없다. 느린 서버(Railway)에서만 자연스럽게 등장.
- **모양은 A안 "책등 3권".** 선반 위 책 세 권이 차례로 살짝 떠오르고 가운데 한 권만 레드. 시안 `design/mockups/page-loader.html`에서 B안(페이지 넘김)과 라이트·다크로 비교 — B는 작은 크기에서 뭉개져 탈락.
- **화면 중앙 오버레이 + 클릭 차단.** 바탕 토큰을 72% 반투명으로 깔아 라이트·다크 자동 대응, 이동 중 중복 클릭을 막는다. 상단 진행 바가 아니라 "스피너"를 요청했으므로 중앙 배치.
- **접근성**: `role="status"` + `aria-live="polite"`, `prefers-reduced-motion`이면 튀어오르기 대신 은은한 깜빡임, 단순 화면은 블러 없이 더 진하게 덮음.

## 버린 대안

- **B. 페이지 넘김 애니메이션**: 36px 크기에서 책 모양이 안 읽힘.
- **상단 얇은 진행 바(NuxtLoadingIndicator)**: 미니멀하지만 눈에 안 띄어 "안 눌린 줄 알고 다시 누르는" 문제를 못 푼다.
- **기존 `LibrarySearchLoader`(서가 걷는 장면) 재사용**: 검색 전용 연출이라 매 이동마다 쓰기엔 무겁다.
