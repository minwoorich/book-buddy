# 2026-09-13 관리자 대시보드 · 통계 기능 추가

민우 지시로 기능 2종 추가.

## 추가된 기능

1. **관리자 대시보드** (`/admin`) — "대출, 반납, 신고, 책 등록 etc" 간단하게
   - 요약 카드(대출 중/연체/신청 대기/신고 대기) + 최근 대출·반납 관리(강제 반납)
   - 희망도서 신청 승인/거절 (승인 시 책 등록 연계)
   - 책 등록(알라딘 검색 기반)/삭제
   - **신고 처리** — Claude 해석: 분실·파손(책) 또는 부적절 게시물/리뷰 신고를 `reports` 테이블로 통합, 사용자가 접수하고 관리자가 처리
   - 접근 제어: `users.role`(admin/member) 필드 신설, 데모 수준 헤더 검사
2. **통계** (`/admin/stats`) — 부서별 · 성별 · 나이대별 · 직급별 · 계열사별 · 팀별
   - `users`에 gender, birth_year, position 필드 추가
   - 그룹별 대출·완독량 막대 차트(CSS/SVG, 라이브러리 없이) + 인당 평균

## 시드 영향

- 직원 시드에 성별/출생연도/직급 분산, 관리자 1명 포함
- 신고 샘플 1~2건

## 미해석/확인 필요

- "신고"의 정확한 의도가 다르면(예: 연체자 신고 등) 알려줄 것 — 현재는 분실·파손·부적절 콘텐츠 신고로 구현 예정
