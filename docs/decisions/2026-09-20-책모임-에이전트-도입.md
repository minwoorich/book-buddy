# 책모임(에이전트 운영 사내 독서모임) 도입 결정

날짜: 2026-09-20 · 결정자: 민우
설계서: [[../superpowers/specs/2026-09-20-책모임-design]]

## 맥락

AI 챌린지 발표·데모가 끝났고, 이후 작업은 민우 개인 업그레이드 단계다. 우선순위가 "과정 증명 / 3분 데모 안전성"에서 **제품 완성도**로 바뀌었다. 그래서 기능을 데모 리스크로 깎지 않고, 단계로 쪼개되 최종적으로 전 범위를 구현한다.

"더 획기적인 AI agentic 기능"을 찾는 논의에서 출발했다. 현재 책벗은 도구 12개를 가진 반응형 에이전트라 "시키면 한다"까지만 되어 있고, 스스로 목표를 세우거나 시간을 가로질러 움직이지 않는다는 진단이 출발점이었다.

## 검토한 4가지 방향

| 안 | 내용 | 결과 |
|---|---|---|
| A. 목표 위임형 독서 플래너 | 한 문장 목표 → 다단계 계획 → 대출/예약/희망도서/캘린더 집행 | 보류 |
| B. 야간 자율 사서 | 크론 에이전트가 DB를 훑어 판단·초안 → 관리자 승인 큐 | 보류 |
| **C. 에이전트가 운영하는 북클럽** | 같은 책 읽은 사람 매칭 → 토론 질문 → 장소·일정 조율 → 알림 | **채택** |
| D. 서가 멀티모달 | 서가 사진 → 책등 인식 → 즉시 추천·대출 | 보류 |

C를 고른 이유: 지금 따로 노는 **책 기능과 장소 기능을 하나의 목적으로 묶는** 유일한 안이고, `loans`·`reviews`에 이미 쌓여 있지만 화면 어디에도 드러나지 않는 "같은 책을 읽은 동료" 데이터를 실제 가치로 바꾼다.

## 논의에서 확정된 것

1. **회고형으로 간다** — 이미 완독한 사람끼리 묶는다. 진행형(같이 읽어나가기)은 일정·진도 추적과 재고 N권이 필요해 범위 밖.
2. **자율 탐지 + 관리자 승인** — 에이전트가 스스로 후보를 찾되, 초대 발송 전에 사람이 한 번 본다.
3. **매칭에 기준과 쿼터를 둔다** — "시도 때도 없이 모으지 않는가"라는 지적에서 나왔다. 주 1회 실행 · 회당 2건 · 사람 동시 1개 + 4주 쿨다운 · 책 3개월 쿨다운. 미니시드 기준 주당 1~2개.
4. **정원 3~5명**, 별점이 갈릴수록 가점(토론이 되려면 이견이 필요하다), 부서 2개 이상 강제.
5. **새 페이지 `/clubs`("책모임", 메뉴 라벨 "모임")** 을 만든다.
6. **실제 장소 예약은 하지 않는다** — 외부 카페라 불가능. 대신 **시스템 내부에 일정을 잡아두고**(`clubs.meet_at`) 독서 달력에 띄운다. 이 구분을 화면 문구에도 반영한다("예약" 아님, "장소 확정").
7. **알림은 범용 테이블로** 만든다. 책모임 전용으로 만들지 않아야 이후 연체·예약 알림에 그대로 쓸 수 있다.

## 버린 대안

- **완전 자율(승인 없음)** — 잘못된 매칭이 그대로 사람에게 노출된다.
- **사용자가 씨앗을 던지는 방식** — 자율성이 사라져 이 기능의 핵심이 없어진다.
- **별도 일정 테이블** — 모임당 일정이 하나뿐이라 `clubs.meet_at`으로 충분하다. 회차 개념이 생기면 그때 분리.
- **외부 발송(메일·슬랙)** — 인프라가 없고 사내 계정 연동이 범위를 크게 키운다. `.ics` 내보내기로 대체.

## 설계 중 발견한 것

- **장소 태그 6종이 전부 "혼자 읽기" 기준이다.** `quiet`(조용해요)가 개인 추천에서는 최상위 신호인데, 떠들어야 하는 모임에서는 무의미하거나 역신호다. 그래서 모임 전용 장소 점수식을 분리하고 `quiet`를 중립으로 둔다.
- **`ReadingCalendar`가 `loans`에 강결합돼 있다.** 모임 일정을 얹으려면 `events` 배열로 일반화해야 하고, 그 과정에서 지금 없는 **반납 예정일 표시**가 덤으로 생긴다.
- **모임이 장소 후기의 수도꼭지가 된다.** 모임 다음 날 후기 요청 → `place_reviews` 유입 → 다음 모임 장소 추천 품질 향상. 지금 후기는 자발적으로만 늘어난다.

## 단계

1단계 뼈대+알림 → 2단계 일정(달력·충돌 회피·ics) → 3단계 장소 연동·플라이휠. 순서일 뿐 범위 축소가 아니다.
