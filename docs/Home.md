## 운영 규칙

- 사람의 결정이 나오면 → `decisions/`에 날짜별 파일로 기록 (무엇을, 왜, 어떤 대안을 버렸는지)
- 작업 세션이 끝나면 → `devlog/`에 그날 한 일과 다음 할 일 기록
- 계획이 바뀌면 → `plans/로드맵`을 갱신 (완료 체크, 새 항목 추가)
- 조사한 외부 지식은 → `references/`에 남겨 다음에 다시 조사하지 않게 한다
